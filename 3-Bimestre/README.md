| 02 | Maior entre dois números | `C++/maior-numero.cpp` | `Python/maior-numero.py` |
| 03 | Contagem de 1 até N | `C++/contagem.cpp` | `Python/contagem.py` |
| 04 | Soma dos números pares | `C++/soma-numeros-pares.cpp` | `Python/soma-numeros-pares.py` |
| 05 | Tabuada com validação | `C++/tabuada.cpp` | `Python/tabuada.py` |
| 06 | Média de notas | `C++/media-notas.cpp` | `Python/media-notas.py` |

## 2. Sistema Lanchonete

Pasta: `Sistema-Lanchonete/`

O sistema usa Python e JSON para cadastrar produtos, controlar estoque e registrar pedidos.

### Parte da Turma A
- Alterar preço de produto
- Remover produto
- Pesquisar produto por nome
- Relatório de vendas

## Como executar os arquivos Python

```bash
python nome-do-arquivo.py
```

ou, no Windows:

```bash
py nome-do-arquivo.py
```
