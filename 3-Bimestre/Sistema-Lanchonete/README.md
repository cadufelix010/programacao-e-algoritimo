# Sistema Lanchonete — Turma A

Projeto do 3º bimestre de Programação e Algoritmos.

## Aluno
Carlos Eduardo Félix

## Objetivo
Criar um sistema em Python executado no terminal, com os dados salvos em arquivo JSON.

## Funcionalidades base
- Cadastrar produto
- Listar produtos
- Fazer pedido
- Ver pedidos realizados
- Persistir os dados em `lanchonete_dados.json`

## Funcionalidades da Turma A
- Alterar preço de produto
- Remover produto
- Pesquisar produto por nome
- Relatório de vendas

## Como executar
Abra esta pasta no VS Code e execute:

```bash
python lanchonete.py
```

No Windows, também pode ser usado:

```bash
py lanchonete.py
```

O arquivo `lanchonete_dados.json` é criado e atualizado automaticamente.
